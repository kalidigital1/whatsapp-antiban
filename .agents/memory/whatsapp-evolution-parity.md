---
name: Evolution WhatsApp parity
description: Product scope for the Evolution connection in the WhatsApp app.
---

Evolution mode should mirror a broad set of WhatsApp Web chat features that the provider actually supports, including synced history and contacts, direct and group chats, media, and reactions. Do not describe the app as having exact WhatsApp Web parity; unsupported provider capabilities remain unavailable.

**Why:** The user chose broad WhatsApp Web parity for this app, while Evolution is unofficial and its API limits which features can be mirrored.

**How to apply:** Prioritize supported chat, group, contact, media, and reaction behavior when extending Evolution mode, and state capability limits plainly rather than implying unsupported functions work.
